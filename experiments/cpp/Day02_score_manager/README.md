# Day02 - Score Manager (C++)

## Features
- Add scores (0~100)
- Show all scores
- Calculate average
- (Bonus) Show max & min
- Robust integer input validation

## How to Run
Compile:
- g++ main.cpp -o app
Run:
- ./app

## Notes
- Uses `std::vector<int>` to store scores
- All user input is validated to avoid crashing on invalid input
